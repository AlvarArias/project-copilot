# Project Copilot

AI copilot for project management — chat + an editable Gantt driven by an
agent with tool-calling, plus RAG over uploaded project documents.

- Full plan and architecture: [`PLAN.md`](./PLAN.md)
- Local setup, Docker, and pending manual steps: [`SETUP.md`](./SETUP.md)

Bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)
(App Router + TypeScript + Tailwind CSS).
